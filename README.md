# 貓貓黑名單客戶端 使用說明

這是黑名單管理桌面工具的使用說明，適合日常操作。

• 登入 API
• 查詢黑名單
• 新增或移除使用者
• 匯入覆蓋與匯出

## 開始使用

1. 開啟程式
2. 進入「認證」區塊
3. 輸入 API Token 後按「登入」

## 查詢

• 查詢全部黑名單
  - 按「查詢全部黑名單」即可

• 查詢單一使用者
  - 輸入 Discord 使用者 ID
  - 按「查詢」

## 新增到黑名單

1. 在「新增至黑名單」輸入：
   • 使用者 ID
   • 操作者
   • 原因（可留空）
2. 選擇模式
   • 🚫 封鎖
   • 🌐 全域封禁
3. 按「新增」

## 移除黑名單

1. 在「移除黑名單」輸入使用者 ID
2. 按「移除」

## 匯入覆蓋

• 按「📤 匯入覆蓋」並選擇 JSON 檔
• 會直接覆蓋整份黑名單資料

## 匯出全部

• 按「📥 匯出全部」並選擇存檔位置
• 會輸出完整黑名單 JSON

## 連線測試

• 在「認證」區塊按「測試連線」

## 提示

• Token 會保存在本機 session.json（Base64 混淆）
• 每次新增、移除、覆蓋都會自動備份到 data/
• 匯入覆蓋前建議先自行備份
